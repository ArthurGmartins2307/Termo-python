# Termo — Jogo de Adivinhação de Palavras

O **Termo** é um projeto inspirado no jogo de adivinhação de palavras em que o jogador precisa descobrir uma palavra secreta por meio de tentativas limitadas. O objetivo é reproduzir a mecânica principal do jogo, explorando a lógica de programação e o desenvolvimento de uma interface interativa.

O projeto foi desenvolvido inicialmente em Python, com a lógica implementada manualmente para execução diretamente no terminal. Posteriormente, foi criada uma interface web utilizando HTML, CSS e JavaScript, com auxílio de Inteligência Artificial para a construção da parte visual.

## Tecnologias utilizadas

- **Python:** desenvolvimento da lógica do jogo e da versão executada no terminal.
- **HTML5:** estrutura da interface web.
- **CSS3:** estilização, organização visual e apresentação do jogo.
- **JavaScript:** interatividade e comportamento da interface web.
- **Inteligência Artificial:** auxílio na criação da interface visual em HTML, CSS e JavaScript.

## Funcionalidades

- Adivinhação de uma palavra secreta.
- Tentativas limitadas para descobrir a palavra correta.
- Indicação visual das letras conforme as regras do jogo.
- Interface web para tornar a experiência mais intuitiva.
- Versão em Python executada diretamente pelo terminal.

## Estrutura do projeto

O projeto reúne duas abordagens para reproduzir a mesma experiência: uma versão baseada em terminal, desenvolvida em Python, e uma interface web voltada à apresentação visual e à interação com o jogador.

## Objetivos de aprendizado

Este projeto foi desenvolvido para praticar conceitos fundamentais de programação, incluindo:

- Construção de lógica condicional e estruturas de repetição.
- Manipulação de strings e caracteres.
- Organização das regras de um jogo.
- Desenvolvimento de interfaces web.
- Integração dos conhecimentos de programação com ferramentas de Inteligência Artificial.

Além de reproduzir a mecânica do Termo, o projeto representa um exercício prático de resolução de problemas e exploração de diferentes tecnologias para construir uma aplicação.

## Como executar

### Versão Python

1. Clone o repositório:

   ```bash
   git clone https://github.com/ArthurGmartins2307/Termo-python.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd Termo-python
   ```

3. Execute o arquivo Python principal:

   ```bash
   python termo.py
   ```

   **Observação:** substitua `termo.py` pelo nome real do arquivo principal, caso seja diferente.

### Versão web

Abra o arquivo `index.html` em um navegador para acessar a interface web, desde que os arquivos HTML, CSS e JavaScript estejam organizados e referenciados corretamente.

## Considerações finais

O Termo é um projeto de prática e aprendizado que combina lógica de programação em Python com desenvolvimento web. A construção manual da lógica e o uso de Inteligência Artificial como ferramenta de apoio para a interface permitiram explorar diferentes etapas do desenvolvimento de software, desde as regras de funcionamento até a experiência visual do usuário.
